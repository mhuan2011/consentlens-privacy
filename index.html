ConsentLens — CMP Inspector

Privacy Policy

Effective date: November 5, 2026 · Extension version 1.0.0

Your scans stay on your device. ConsentLens inspects a website’s consent management implementation in your browser. The extension has no accounts, analytics, advertising, or external scan service. It does not send scan results to the developer or third parties.

1. Scope and purpose

This policy describes how the ConsentLens — CMP Inspector Chrome extension handles information. Its purpose is to identify consent management platforms (CMPs), detect consent banners, and report consent API and Google Consent Mode signals on websites you inspect.

2. Information inspected and included in reports

When a scan runs, ConsentLens processes technical signals from the current page’s main frame. Reports may include:

  • The website hostname and page URL, limited to its origin and path, with query strings and fragments removed.
  • Detected CMP names, matching script or resource URLs, known JavaScript global names, banner selectors, and banner visibility.
  • Consent-related cookie names. Cookie values are not included in reports.
  • Selected responses from TCF, GPP, and US Privacy API checks, such as availability, readiness, version, and supported framework information.
  • Allowlisted Google Consent Mode values from consent commands in the standard dataLayer queue. General data layer payloads are not included in reports.
  • Known tracking resource URLs, resource timing information, the browser’s Global Privacy Control signal, scan timestamps, and diagnostic findings.

Page and resource paths can still contain sensitive information even after query strings and fragments are removed. Review reports before exporting or sharing them.

The scanner reads page signals and calls consent APIs for inspection. It does not click consent banners, submit consent choices, or change website settings. It does not inspect HttpOnly cookies or network response bodies.

3. How information is used and shared

Information is processed locally to produce the scan report, supporting evidence, and toolbar status badge. It is also used for local history and JSON export when you choose those features.

The extension does not transmit scan data to the developer or third parties, sell data, use it for advertising, or use it to train machine learning models. It does not include analytics or remote executable code.

4. Storage and retention

  • Session cache: Scan reports are cached in Chrome’s extension session storage. A tab’s cached report is removed when it navigates or closes. Session storage is cleared when the browser session ends.
  • Preferences: Automatic scanning and history preferences are saved in Chrome’s local extension storage.
  • Optional history: History is disabled by default. When enabled, it keeps up to 30 reports locally in the browser. Turning history off deletes saved history.
  • Exports: Choosing Export saves a JSON report through your browser. The file remains wherever you save it until you delete it yourself.

ConsentLens uses session and local extension storage, rather than Chrome sync storage, for these features.

5. Browser permissions

  • activeTab: Provides temporary access to the current website when you open the extension to inspect it.
  • scripting: Runs the bundled inspection function in the page’s main JavaScript context to access consent APIs and page signals.
  • storage: Stores session reports, preferences, and optional local history.
  • Optional HTTP and HTTPS website access: Requested when you enable Automatic scanning so scans can run after pages finish loading. Automatic scanning is disabled by default. Turning it off removes this optional website permission.

Without optional website access, you can still scan a supported current page by opening the extension.

6. Your choices and deletion

In the extension’s Settings, you can turn Automatic scanning or Save scan history on or off. Select Clear data to remove cached scan reports and saved history. This action does not reset preferences or delete exported files.

You can also manage website access or uninstall ConsentLens through Chrome’s extension settings. Uninstalling removes extension-managed local data; exported files must be deleted separately. Because scan data is not sent to the developer, the developer cannot access or retrieve your locally stored reports.

7. This privacy policy page

The provider hosting this page may process ordinary web request information, such as IP addresses and access logs, under its own privacy practices. Those hosting activities are separate from the extension’s local scan processing.
